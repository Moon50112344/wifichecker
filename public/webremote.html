▶ Hướng dẫn & API contract (cho nhà phát triển Android)

Trang này là CLIENT thuần. Mọi request gửi thẳng tới http://IP_ANDROID:PORT. Không có server trung gian.

GET  /api/status  — trạng thái + thông tin mạng

POST /api/scan/start — bắt đầu quét

POST /api/scan/stop  — dừng quét

GET  /api/scan/results — danh sách thiết bị

Auth: HTTP Basic (account:password). Android server phải gửi header Access-Control-Allow-Origin và xử lý OPTIONS preflight. Nếu file này được phục vụ trực tiếp bởi chính Android server (mở http://IP:PORT), không cần CORS.

Nhập thông tin hiển thị trên app WiFi Checker sau khi chạy lệnh open port 8080.
Kết nối trực tiếp Browser ↔ Android — chỉ hoạt động cùng mạng LAN.
